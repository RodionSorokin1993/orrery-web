# 002: Internationalization

- **Status:** Implemented
- **Related:** [000](./000-overview.md), [001](./001-content-model.md)

## Context

The site ships in English and Spanish. Visitors should land in their language without a
flash of the wrong one, search engines should understand which pages are translations of
each other, and editors should translate documents, not individual fields.

## Requirements

- **R1.** Supported locales: `en` (default) and `es`. All site routes live under `app/(site)/[lang]`.
- **R2.** `proxy.ts` redirects locale-less paths (for example `/blog`) to a locale prefix.
  Priority: the `NEXT_LOCALE` cookie, then `Accept-Language` with q-values, then the default.
- **R3.** Choosing a language in the switcher sets `NEXT_LOCALE` for one year and navigates to the
  translated URL of the current document. When a translation does not exist, it falls back to
  the locale home page instead of a 404.
- **R4.** `<html lang>` matches the route locale. Every page emits `hreflang` alternates for each
  available translation plus `x-default`.
- **R5.** UI strings (navigation labels, chart controls, dates) come from typed dictionaries in
  `src/lib/i18n/dictionaries`. A missing key is a type error, not a runtime surprise.
- **R6.** Numbers and dates use `Intl` with the route locale (`0.5` renders as `50%` in English
  and `50 %` in Spanish).

## Acceptance criteria

| ID  | Criterion                                                      | Verified by                                                  |
| --- | -------------------------------------------------------------- | ------------------------------------------------------------ |
| AC1 | `Accept-Language: es-MX,es;q=0.9` on `/` redirects to `/es`    | `src/lib/i18n/negotiate.test.ts`, `e2e/i18n.spec.ts`         |
| AC2 | Switching language keeps the reader on the translated document | `e2e/i18n.spec.ts`                                           |
| AC3 | `<html lang="es">` on Spanish routes                           | `e2e/i18n.spec.ts`                                           |
| AC4 | Each locale dictionary has the same keys                       | `pnpm typecheck` (dictionaries are typed by the English one) |

## Edge cases

- Unsupported locale in the URL (`/fr/blog`) renders the not-found page.
- Static files, `/studio`, `/api/*`, and metadata routes are never redirected.

## Do not touch

- Slugs of published documents. Changing a slug changes a public URL.
